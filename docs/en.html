GOOD TO KNOW

Before you get started

Do I need Arduino IDE or VS Code?

No. ESP32 Coder is a standalone Windows app. Required SDKs and toolchains can be installed from its interface.

Can I flash a BIN without the source code?

Yes, if you have a ready-made BIN that matches the target board and its flash layout.

Can LittleFS be flashed independently?

Yes. A separate mode writes a prepared LittleFS filesystem image. Use the correct partition address and layout.

Are ESP32-S3 and ESP32-C3 supported?

The app includes ESP32 board families such as ESP32-S3 and ESP32-C3. Available configurations depend on installed components.

Where can I find updates?

Download the latest GitHub Release or use the app’s signed-update check.
